# Svelte Resume Website Template

This is a modern, responsive resume website template built with Svelte, featuring cool SVG graphics and a clean layout. Easily customize your information in the main page.

## Features
- Svelte + TypeScript
- Tailwind CSS for styling
- SVG/CSS graphics for visual appeal
- Responsive design for desktop and mobile
- Sections: About, Experience, Projects, Skills, Contact

## Getting Started

### Install dependencies
```
cd resume-svelte
npm install
```

### Run the development server
```
npm run dev -- --open
```

### Build for production
```
npm run build
```

### Preview production build
```
npm run preview
```

## Customization
- Edit `src/routes/+page.svelte` to update your name, profession, about, experience, projects, skills, and contact info.
- Replace the avatar image if desired (currently uses the Svelte logo as a placeholder).
- Adjust styles or add more sections as needed.
